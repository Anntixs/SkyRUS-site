# SkyRUS — сайт дивизиона

Сайт русскоязычного дивизиона **SkyRUS** сети виртуальной авиации SkyNetwork: регионы, новости, допуски, документы, личный кабинет студента и учебный центр для инструкторов и менторов. ASP.NET Core 8 (Razor Pages), SQLite.

## Разделы

**Для всех**
- **Главная**: о дивизионе, как стать диспетчером, новости, регионы.
- **Регионы** (`/regions`): РПИ дивизиона с аэродромами, число студентов и действующие допуски в каждом РПИ. При первом запуске создаются 14 РПИ России и основные аэродромы.
- **Новости**, **Документы** (текст или ссылка на файл).
- **Допуски** (`/permits`): все действующие допуски с фильтром по РПИ.

**Личный кабинет** (`/cabinet`). Вход по CID и паролю SkyNetwork: пароль проверяет сайт сети, на сайте SkyRUS он не хранится. Имя и рейтинги берутся из сети при каждом входе. В кабинете:
- заявка на обучение: РПИ, аэродром приписки, пара слов о себе;
- статус заявок и причина отказа;
- свои допуски;
- экзамены на рейтинг и решение супервайзера сети.

**Учебный центр** (`/tc`) — только для сотрудников, для остальных его нет (404):
- **Заявки**: открытые и архив, фильтр по РПИ. В карточке заявки можно «Взять в обучение» или отказать с причиной, которую увидит студент.
- **Студенты**: список с фильтром по РПИ и поиском. Колонки: CID, рейтинг, имя, РПИ, последнее изменение, текущий статус, число допусков. Карточку можно открыть и по CID любого участника сети.
- **Карточка студента** — дневник, который видят только сотрудники:
  - аттестации (протоколы) с результатом и статусом заявки на рейтинг;
  - новый протокол;
  - РПИ и аэродром приписки;
  - допуски (выдать, отозвать);
  - журнал с комментариями инструкторов и событиями системы.
- **Протокол аттестации**:
  - пункты вида аттестации оцениваются от 1 до 5, внизу комментарий;
  - аттестация **сдана, если ни один пункт не ниже 3**; общая оценка — среднее;
  - после закрытия оценки не меняются.
- **Экзамен на рейтинг**:
  - после сданного экзамена сайт сам отправляет в SkyNetwork заявку на рейтинг: экзаменатор, дата, оценка, комментарий и ссылка на отчёт об экзамене для супервайзера (`/report/{id}?t=…`);
  - заявку одобряет супервайзер в разделе «Заявки на рейтинг» сайта сети;
  - сайт каждые 5 минут забирает решение, записывает его в журнал и обновляет рейтинг студента;
  - если сеть была недоступна, заявка уйдёт при следующей проверке.

**Роли**

| Роль | Что может |
|---|---|
| Ментор | заявки, студенты, журнал, зачёты по теории и практике |
| Инструктор | всё, что ментор, плюс экзамены на рейтинг и допуски |
| Администратор | всё, плюс сотрудники, виды аттестаций, регионы, новости и документы (`/admin`) |

Первых администраторов задаёт настройка `Site:Admins` (CID через запятую), остальных сотрудников они добавляют сами в разделе «Сотрудники».

**Виды аттестаций.** При первом запуске создаются по три вида на каждый этап: DEL/GND → S1, TWR → S2, APP → S3, CTR → C1. Это зачёт по теории, зачёт по практике и экзамен на рейтинг. Администратор меняет пункты (по одному в строке, пояснение через «|»), добавляет новые виды и скрывает ненужные. Уже созданные протоколы хранят свою копию пунктов.

## Связь с сетью SkyNetwork

Сайт работает через API дивизионов сайта сети (`/api/division/v1`), нужен ключ дивизиона:

1. Администратор сети на сайте сети: «Заявки на рейтинг» → «Ключи API дивизионов» → код `SKYRUS` → «Выдать ключ».
2. Ключ — в настройку `Site:NetworkApiKey`, адрес сайта сети — в `Site:NetworkUrl`.

Что используется:
- `POST /auth` — вход;
- `GET /members/{cid}` — данные участника;
- `POST /rating-requests` и `GET /rating-requests/{id}` — заявки на рейтинг.

## Настройки

`appsettings.json`, раздел `Site`, или переменные окружения `Site__…`:

| Настройка | Что это |
|---|---|
| `Database` | файл SQLite сайта |
| `NetworkUrl` | адрес сайта сети, например `https://sky.network.npzy2.us` |
| `NetworkApiKey` | ключ API дивизиона (`skd_…`) |
| `Admins` | CID администраторов SkyRUS через запятую |
| `PublicUrl` | адрес этого сайта, для ссылки на отчёт об экзамене |
| `BehindProxy` | `true`, если сайт стоит за Caddy или nginx |

## Запуск локально

```bash
dotnet run --project src/SkyRus.Site -- --Site:NetworkUrl=http://127.0.0.1:8000 --Site:NetworkApiKey=skd_... --Site:Admins=1
```

Сайт откроется на http://127.0.0.1:8100.

## Установка на сервер

На сервере сети (Ubuntu, .NET 8 SDK и Caddy уже стоят). Сначала направьте DNS-запись домена SkyRUS на сервер, затем выполните под root:

```bash
git clone https://github.com/Anntixs/SkyRUS-site.git ~/SkyRUS-site
bash ~/SkyRUS-site/deploy/install.sh skyrus.example.com
```

Скрипт:
- спросит адрес сайта сети, ключ API и CID администраторов (сохранит их в `/etc/skyrus/site.env`, доступ только у root);
- создаст службу `skyrus-site` (порт 8100, только локально);
- добавит домен в Caddy (HTTPS выдаётся автоматически);
- соберёт и запустит сайт.

Обновление:

```bash
bash ~/SkyRUS-site/deploy/update.sh
```

Логи: `journalctl -u skyrus-site -n 50 --no-pager`. База: `/var/lib/skyrus/skyrus.db`.
